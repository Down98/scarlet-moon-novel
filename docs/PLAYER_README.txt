붉은 달 아래, 길을 잃다
플레이 테스트 배포본

1. ZIP 파일을 먼저 전부 압축 해제하세요.
2. 압축을 푼 폴더의 index.html을 Chrome 또는 Edge로 여세요.
3. 「이야기 시작」을 누르면 플레이할 수 있습니다.

별도 설치나 인터넷 연결은 필요 없습니다.
index.html과 assets, css, js 폴더를 함께 유지해 주세요.
ZIP 내부의 index.html만 바로 열면 이미지와 소리가 나오지 않을 수 있습니다.

조작
- 클릭 / Space / Enter: 다음 대화, 타이핑 중에는 문장 즉시 표시
- 선택지: 원하는 답변 클릭
- A: 자동 진행 켜기 / 끄기
- H: 대화창 숨기기 / 표시
- 환경 설정: 글자 속도, 자동 진행 간격, 소리별 음량

소리
처음 클릭하거나 키를 누른 뒤 음악과 효과음이 시작됩니다.
오른쪽 위 소리 버튼으로 음소거를 전환할 수 있습니다.
배경음악, 버튼/장면 효과음, 텍스트 소리는 각각 조절할 수 있습니다.
인물 음성 더빙은 없습니다.

저장
자동 저장과 수동 저장 3칸을 지원합니다.
기록은 플레이한 브라우저에 보관됩니다. 시크릿 모드나 브라우저 데이터 삭제 시
기록이 유지되지 않을 수 있습니다. 이어서 플레이할 때 같은 폴더와 브라우저를 사용하세요.

플레이 후 감상을 보내 주실 때
어색한 대사, 상황과 다른 표정, 소리나 화면 문제, 헷갈리는 선택지를 알려 주세요.
가능하면 해당 대사나 화면 캡처, 사용한 브라우저를 함께 남겨 주세요.
